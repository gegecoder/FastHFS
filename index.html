FastHFS 是一款跨平台桌面文件服务工具：支持挂载本地目录，设置访问权限并生成带密码与时效的分享链接，局域网内的设备即可便捷访问本地文件。

核心能力

从选一个目录，到全屋共享

不用装 NAS、不用写脚本、不用配置 Web 服务器。选目录、开权限、点启动，局域网文件服务即刻可用。

三分钟开启文件服务

桌面面板里选目录、设别名与权限，点击「启动文件服务」即可在局域网提供 HTTP 访问，无需命令行与额外依赖。

目录挂载与细粒度权限

任意本地目录挂载为对外别名，浏览 / 下载 / 上传 / 删除逐项开关，忽略规则可过滤不希望暴露的文件。

分享链接三种模式

preview 只读预览、download 可下载、collect 仅收集上传；可设访问密码（bcrypt 存储）、有效期与最大访问次数。

断点续传与大文件

上传基于 tus 分片协议，网络中断或关闭页面后可从未完成处继续；目录可一键打包为 ZIP 下载。

限速与安全防护

下载 / 上传独立限速、单文件大小上限、上传后缀黑名单、单 IP 每分钟限流；匿名访问支持 deny / readonly / upload 三档策略。

托盘常驻与扫码访问

关闭窗口即隐藏到系统托盘，服务不中断；访问地址可一键复制或生成二维码，手机扫码直达分享页面。

服务能力

浏览、下载、上传、分享，一套面板全管

管理端负责挂载与权限，访客端用浏览器直接访问，脚本可通过 Basic Auth 调用同一套 HTTP API。

01

浏览与下载

打开地址即可浏览目录，单文件下载或整个目录打包 ZIP，图片、文本与音视频支持在线预览。

管理端 按挂载单独控制浏览与下载权限，忽略规则隐藏敏感文件。
访客端 目录树与面包屑导航，文件预览、ZIP 打包下载，移动端自适应。
02

上传与收集

拖拽或分片上传大文件，进度实时可见，断网后可从断点继续，适合手机向电脑回传文件。

管理端 单独开关上传权限，设置单文件上限与后缀黑名单，上传速率可限。
访客端 tus 分片续传、多文件队列、剩余时间估算，收集模式下只允许上传。
03

分享与账号

为文件或目录生成独立分享链接，支持密码、时效与访问次数限制，失效后立即无法访问。

管理端 分享列表集中管理，详情展示次数、密码状态、有效期与完整链接。
访客端 账号登录后获得全局权限；脚本可用 HTTP Basic Auth 直接调用接口。
技术架构

原生桌面，全离线运行

基于 Wails v3 构建，Go 负责文件服务与系统能力，Vue 3 负责界面，全部资源内置进二进制，不依赖 CDN。

  • 原生窗口与托盘系统 WebView 渲染，窗口与托盘图标运行时生成；关闭窗口隐藏到托盘，退出前自动停止服务。
  • Go 文件服务引擎Gin 路由、tus 分片、ZIP 打包、限速限流、SQLite（纯 Go）存储与 JWT 鉴权全部由 Go 处理，单文件部署。
  • Vue 3 管理面板Vue 3 + TypeScript + Element Plus，首页、挂载、分享、账号、设置与日志集中管理，中英双语与深浅主题。
  • 离线可用管理面板与访客站点全部内嵌，断网环境同样可以提供局域网文件服务，无需联网校验。
Wails v3

Go × Vue × WebView

把文件 I/O、权限校验与限速交给 Go，把配置与观测留在清爽的原生界面里。
